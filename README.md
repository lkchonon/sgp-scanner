# SGP Scanner — Sharp Parlay Engine

Free single-page parlay scanner powered by Gemini AI. Auto-scans NBA, MLB, NHL, NFL. Applies 5/5 floor rules. Builds verified same-game parlays with full + safe versions.

## Setup

**1. Get free Gemini API key**
→ https://aistudio.google.com/app/apikey (free, no credit card)

**2. Deploy to GitHub Pages**
- Upload `index.html` to a new GitHub repo
- Settings → Pages → Source: main branch / root
- Your app goes live at `https://yourusername.github.io/your-repo-name`

**3. Open the app, paste your API key, hit Save & Scan**

Key is stored in your browser — enter once per device.

## How it works
- Gemini 2.0 Flash + Google Search grounding pulls live data
- 5/5 floor rule: prop must hit in all 5 of last 5 games
- Auto-discards injured players
- Verifies lines on FanDuel/DraftKings
- Builds 3–12 leg parlays with Full + Safe versions
- Free tier: 1,500 scans/day
